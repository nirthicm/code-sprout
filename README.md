# 🌱 Code Sprout

A kid-friendly coding website. Make animations and games with:

- 🧩 **Blocks**: drag-and-drop blocks with sprites, backdrops, sounds and a pen
- 🐍 **Python** and ⚡ **JavaScript**: type real code that moves sprites on the stage
- 🖌️ A sprite library (300+ sprites), Surprise, Paint and Upload
- 🌱 **Sprout**, an AI buddy who shares ideas and hints but never writes the code for you
- 🌍 Accounts, 📁 folders, 🚀 sharing, Explore and comments

## Run it

Open `index.html` in a web browser. Everything is in that one file.

## Good to know

Some features use Claude's artifact runtime and only work when the page is
opened as a Claude artifact on claude.ai:

- Sprout the AI buddy and the 🎤 microphone
- Accounts, saving, folders, sharing, Explore and comments

When opened anywhere else (for example straight from this repository or on
GitHub Pages), the page runs in guest mode. You can still code with blocks,
Python and JavaScript, use the stage and sprite library, paint and upload
sprites, but projects aren't saved and Sprout can't chat.

Libraries are loaded from public CDNs: Blockly, CodeMirror and Skulpt.
